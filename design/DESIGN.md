# remcli — DESIGN.md

Мобильный пульт управления AI-агентами (Claude / Codex / Gemini / Cursor), P2P, E2E, без облака.
Характер: инструмент разработчика, терминальная эстетика, спокойствие и точность.

## Структура design/
- `DESIGN.md` / `MOTION.md` — спецификации (принципы, навигация, статусы, PWA, анимации).
- `tokens.css` — CSS-переменные shadcn-темы (light + dark) + статусные цвета.
- `screens/` — TSX-экраны с Tailwind: connect, home, chat, new-session, terminal, zen, settings, palette; общие примитивы — `components.tsx`.
- `assets/` — logo.svg, logo-mono.svg, wordmark.svg, favicon.svg, app-icon-1024.png, app-icon-maskable.png, splash.png.
- Setup (шрифты Geist, tailwind-конфиг статусов) — `README.md`.

## Стек дизайна
- shadcn/ui (Radix + Tailwind), tailwindcss-animate. Никаких кастомных контролов без нужды.
- Шрифты: **Geist** (UI) + **Geist Mono** (код, пути, имена сессий, статусы, метаданные). Моно-акценты — часть идентичности.
- Палитра: zinc-нейтрали + один акцент **emerald** (dark `#34D399`, light `#059669`). Primary-кнопка — контрастная (белая/чёрная), emerald зарезервирован за брендом, фокусом, «Разрешить» и статусом running.

## Сетка и плотность
- База отступов 4px: 4 / 8 / 12 / 16 / 24 / 32. Поля экрана 16–20px.
- Радиусы: 6 (мелкие контролы), 8 (кнопки/инпуты), 12 (карточки), 16+ (sheet).
- Плотность Linear-like: строки списков 56–64px, кнопки 36px (mobile CTA 44–52px), текст чата 14px, метаданные mono 10–11px. Тач-цели ≥44×44.

## Типографическая шкала
22/600 заголовок экрана · 17/600 секция · 14/400 текст чата (1.55) · 13/500 кнопки и строки · 12/400 вторичный · mono 13 пути · mono 11 код и статусы · mono 10 метки.

## Навигационная модель
- **Нижние табы (3):** Сессии · Задачи (Zen) · Настройки. Зона большого пальца, safe-area снизу.
- **Push-экраны** (свой «назад», без браузерного): Чат сессии → Терминал.
- **Sheet/Drawer:** новая сессия, resume-пикер, выбор модели/машины, меню сессии (остановить/переименовать).
- **Dialog:** только подтверждение остановки и удаления машины.
- **Command Palette (⌘K / иконка поиска):** сессии + действия. На десктопе — глобально.
- FAB «+ Сессия» на Home, над табами справа.

## PWA (standalone, iPhone-first)
- `display: standalone`, высота 100dvh, `viewport-fit=cover`; отступы `env(safe-area-inset-top/bottom)` — шапка и табы учитывают чёлку/home-индикатор.
- `theme-color`: dark `#09090B`, light `#FAFAFA` (media prefers-color-scheme). Терминал всегда тёмный `#050507`.
- Иконки: `assets/icon-1024-dark.png` (основная), maskable — знак в центральных 62%; light-вариант для белых тем.
- Splash: фон `#09090B`, знак 52px + wordmark, курсор мигает (см. MOTION.md §9), затем fade в Home 250ms.
- Никакой опоры на браузерный хром: свои кнопки «назад», pull-to-refresh отключён, overscroll-behavior: none.

## Язык интерфейса
Система — русский (10 локалей в настройках), контент терминала/кода/путей — как есть (EN). Тон: сухо-технический, mono-строки для системных сообщений («— сессия завершена · exit 0 —»). Без шуток и эмодзи.
