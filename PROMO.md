# Remcli

**Телефон — в руке, код — дома.**

Remcli — remote CLI для AI coding-агентов. Запускайте рабочие сессии на своём компьютере и управляйте ими с телефона: пишите агенту, следите за ходом работы, подтверждайте действия и возвращайтесь к нужному терминалу из любого места.

- При установленном `cloudflared` основной удалённый режим — `npm run start:tunnel`: HTTPS Cloudflare Tunnel для работы вне дома. В одной Wi-Fi сети достаточно `npm start`.
- Никаких аккаунтов Remcli, почты и паролей. Телефон подключается по QR-коду с личным ключом; проект, агент и переписка остаются на вашем компьютере.
- Несколько сессий, выбор папки и доступных моделей, уровень размышления, права доступа, tool calls и запросы разрешений — в одном интерфейсе.
- Начните на компьютере, продолжите с телефона и вернитесь к той же сессии в терминале. Codex уже работает как общая нативная сессия; Cursor поддерживает запуск и resume.
- Есть desktop-режим, мобильный интерфейс, локальный Джарвис, Whisper и озвучивание ответов.
