# Remcli

## Короткий анонс

Remcli — P2P web/PWA-клиент, который позволяет управлять AI coding-agent сессией с телефона или браузера, пока CLI работает на вашем Mac или Linux.

Запускаете Codex в рабочем окружении, сканируете QR-код и видите сессию, сообщения, статусы и разрешения в Remcli. Для Codex телефон и терминал работают с одной нативной сессией: можно начать работу на компьютере и продолжить с телефона.

- Прямое подключение к локальному daemon по LAN, без собственного cloud backend Remcli.
- Опциональный cloudflared tunnel для доступа вне локальной сети.
- Codex — основная проверенная интеграция; Cursor доступен для запуска и resume.
- По желанию: Джарвис через LM Studio, локальный Whisper для голосового ввода и озвучивание ответов.
