# Remcli

**Телефон — в руке, код — дома.**

Remcli — remote CLI для AI coding-агентов. Запускайте несколько рабочих сессий на своём компьютере и управляйте ими с телефона: пишите агенту, видьте tool calls, подтверждайте разрешения, выбирайте модель и возвращайтесь к нужной задаче из любого места.

- При установленном `cloudflared` `npm run start:tunnel` открывает HTTPS Cloudflare Tunnel для удалённой работы; в одной Wi-Fi сети достаточно обычного `npm start`.
- Нет аккаунта Remcli, почты и пароля: телефон подключается по QR-коду с личным секретным ключом.
- Проект и агент остаются на вашем компьютере; содержимое сообщений и сессий шифруется.
- Codex уже работает как одна нативная сессия на терминале и телефоне. Cursor поддерживает запуск и resume; Claude Code и Gemini CLI следующие в очереди.
- Есть полноценный desktop-режим, мобильный интерфейс, локальный Джарвис, Whisper и озвучивание ответов.
